# Martin & Dominika — romantyczna strona

## Uruchomienie
Otwórz `index.html` w przeglądarce.

## Zawartość
- licznik od 31.01.2026,
- romantyczny/cute design,
- dwie przesłane fotografie,
- oś czasu,
- sekcja z piosenką „Perfect”,
- animowane serduszka,
- ukryta wiadomość/niespodzianka,
- wersja responsywna na telefon.

## Dodawanie kolejnych zdjęć
Wrzuć zdjęcia do folderu `assets`, a następnie dodaj kolejne karty `.memory` w sekcji `#wspomnienia`.

## Dokładna godzina rozpoczęcia
W `index.html` znajdź:
`const startDate = new Date(2026, 0, 31, 0, 0, 0);`
i zmień godzinę, jeśli chcesz liczyć od konkretnego momentu.
